PACT / DEMONSTRATION

Privacy

Pact is a synthetic-data demonstration. The sample staff, interview quotes, events and findings are fictional. Do not enter patient data or other real sensitive information.

What is collected

After an administrator opts in, the demo can collect event flags, event names, role labels, pseudonymous actor hashes used to enforce the minimum group size, and optional pattern tags matched in the browser. Usage events contain no patient data, claim notes or other free text. When monitoring is off, the claim page sends no usage events.

Interview processing and service providers

Chrome's speech recognition may send audio for transcription to Google. Interview transcripts are sent to Anthropic to generate questions and organize evidence. Question text may be sent to ElevenLabs to create speech. Do not conduct a real interview without informed consent and appropriate approval for these providers. The software does not promise that spoken content can never include sensitive information.

How information is used and displayed

Usage is summarized by role to compare observed behaviour with the demo contracts. Groups smaller than five people are suppressed. Actor hashes are used to count people for this floor and are not displayed. The tool is not for individual performance review, and its findings are not a substitute for human review.

Opt-in, controls and retention

Drift monitoring is off by default. An administrator can enable it, choose watched contracts, control notes-pattern matching and set the configured retention period to 30 or 90 days. Settings changes are recorded in the local audit log. Turning monitoring off with the delete option removes stored live events. Usage events older than the configured retention period are deleted on server start. All stored demo data will be deleted after the event. Staff must be told what is measured before monitoring is enabled.

Sharing and external connections

The Software Factory feature is a local simulated stub; no live Software Factory connection is made. The evidence board is a local demonstration surface. This demo does not provide production access controls or encrypted storage and should not be used with real personal, health or confidential data.
