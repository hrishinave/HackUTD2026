# Role-play script: Billing clerk 2 (interview INT-01)

Use this when a teammate plays this person in rehearsal. This is the main demo interview (INT-01). Stay in character, answer naturally, and don't volunteer anything in "Only if asked". Everything here is fictional demo data.

## Who you are

- Billing clerk for 4 years. You handle most imaging claims, so prior authorization is a big part of your day.
- Friendly and talkative, but you describe what you do, not why.

## What you say freely

- Early, about prior auth: "If it needs prior auth I put the number in the notes, or sometimes just 'see fax'." (C-01 evidence; give this when asked where the auth number goes, ideally to the AI question Q-12)
- "Pretty much every imaging claim for Medicare Advantage needs one." (C-01 population and frequency; ideally an answer to Q-14)
- Later in the interview: "Honestly we mostly just write 'see fax'." (X-2, side b, which contradicts billing clerk 1)

## What actually happens (for the facilitator, not to say)

- You really type "AUTH SEE FAX" or "AUTH 48213..." because claims without "AUTH" in the notes get returned (PA-SCAN). You've forgotten the "AUTH" part is what matters. This is a say-vs-do gap the logs show.

## Only if asked

- **Coverage changes (RETRO-ELIG):** you never mention this on your own. Only when asked something like "What happens when a patient's coverage changes after the visit?", answer: "Oh, that. If coverage changes after the visit, it lands in my queue and I re-run eligibility." (C-04 evidence; ideally an answer to the AI code-gap question Q-19)
- **The PA-NUM field:** if asked about it: "There's a field for it? I've never used it. The system doesn't care what's in there."

## Cues the agent should pick up

- "Or sometimes just 'see fax'" and "mostly just write 'see fax'" (an inconsistency, and a contradiction with clerk 1).
- "I've never used it" (a ghost feature in the legacy app).
- Silence about coverage changes until asked (a hidden rule only the code reveals).
